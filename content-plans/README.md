# YouTube channel content plans

This folder contains one polished PDF for each channel. Each plan includes channel positioning, a 30-day publishing calendar, four long-form video scripts designed for 10+ minutes, Shorts packages, SEO metadata, thumbnail direction, KPIs, monetization ideas, and production checklists.

## PDFs

- `pdfs/harish-vlogs.pdf` - German Shepherd life, training, puppy care, and family stories.
- `pdfs/harish-tiny-kitchen.pdf` - Small-space cooking, one-pan systems, budget meals, and miniature-food packaging.
- `pdfs/priyacreatives-fashion.pdf` - Rangoli, festival DIY, simple fashion, and Telugu-friendly creative lifestyle content.

## Rebuild the PDFs

From the workspace root:

```text
npm install
npm run build:pdfs
```

The generator is `tools/generate-pdfs.js`. Replace placeholders such as `[puppy name]`, actual local prices, links, and real footage details before recording or publishing.

## Important publishing notes

- Use the plans as production blueprints, not as claims about guaranteed performance.
- Replace generic examples with real results and real audience language.
- Disclose sponsorships, gifted products, and affiliate links.
- Do not purchase or automate views, clicks, subscribers, comments, or watch time.
- For dog content, use humane training and consult a qualified veterinarian or trainer for health or behavior concerns.
